# สารบัญไฟล์ / Template — บริษัท เอ็นพีซี จำกัด

> เอกสารสมมติสำหรับ demo — รวมที่อยู่ของไฟล์ที่พนักงานถามหาบ่อย

## เอกสารขาย (Sales)
- **Template ใบเสนอราคา (Quotation)** — เวอร์ชันล่าสุด v3.2
  ที่อยู่: Google Drive > NPC Shared > Sales > Quotation-Template-v3.2.xlsx
  ลิงก์: https://drive.example.com/npc/quotation-template
- **Template สัญญาจ้างงาน/บริการ (Service Agreement)**
  ที่อยู่: NPC Shared > Legal > Service-Agreement-Template.docx
  ลิงก์: https://drive.example.com/npc/service-agreement
- **Slide เทมเพลตนำเสนอลูกค้า (Pitch Deck)**
  ที่อยู่: NPC Shared > Sales > NPC-PitchDeck-Template.pptx

## เอกสารการเงิน/บุคคล
- **แบบฟอร์มเบิกค่าใช้จ่าย (Expense Claim Form)**
  ที่อยู่: NPC Shared > Finance > Expense-Claim-Form.xlsx
  ลิงก์: https://drive.example.com/npc/expense-form
- **แบบฟอร์มขอซื้อ (Purchase Request Form)**
  ที่อยู่: NPC Shared > Procurement > PR-Form.xlsx
- **แบบฟอร์มใบลา (กรณีระบบ HR ล่ม)**
  ที่อยู่: NPC Shared > HR > Leave-Form.pdf

## เอกสารโปรเจกต์
- **Template เอกสารสรุปโปรเจกต์ (Project Charter)**
  ที่อยู่: NPC Shared > Projects > Project-Charter-Template.docx
- **Template รายงานประชุม (Meeting Minutes)**
  ที่อยู่: NPC Shared > Projects > Meeting-Minutes-Template.docx
